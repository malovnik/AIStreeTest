# 🎁 БЕСПЛАТНЫЙ ГИД: 50 Промптов для TeleChat, которые сэкономят вам 10+ часов в неделю

## Введение

Этот гид содержит 50 готовых промптов для TeleChat, которые вы можете использовать прямо сейчас. Каждый промпт протестирован и оптимизирован для максимальной эффективности.

## 📝 Категория 1: Контент-маркетинг (10 промптов)

### 1. Генерация идей для контента
```
Ты эксперт в контент-маркетинге. Мне нужно 20 идей для постов в блог на тему [ваша тема].

Целевая аудитория: [опишите аудиторию]
Тон: [профессиональный/дружелюбный/экспертный]

Для каждой идеи укажи:
- Заголовок
- Краткое описание (2-3 предложения)
- Целевые ключевые слова
- Предполагаемый уровень интереса читателей (1-10)
```

### 2. Написание email-рассылки
```
Напиши email-письмо для моей аудитории с целью [продать/информировать/привлечь].

Продукт/Услуга: [описание]
Целевая аудитория: [описание]
Длина: 300-400 слов

Структура:
1. Цепляющая тема письма
2. Персонализированное вступление
3. Проблема, которую решает продукт
4. Уникальное предложение
5. Социальное доказательство
6. Сильный call-to-action
```

Требования:

## 🎓 Бонус: Как создавать свои промпты

### Формула эффективного промпта:

1. **Роль**: Определите роль для AI ("Ты эксперт в...")
2. **Контекст**: Предоставьте необходимую информацию
3. **Задача**: Четко сформулируйте, что нужно сделать
4. **Формат**: Укажите желаемый формат ответа
5. **Ограничения**: Укажите лимиты (длина, стиль, etc)
6. **Примеры**: Если нужно, дайте примеры желаемого результата

### Пример применения формулы:

**Плохой промпт:**
"Напиши статью про маркетинг"

**Хороший промпт:**
```
[Роль] Ты эксперт в digital-маркетинге с 10-летним опытом.

[Контекст] Я веду блог для малого бизнеса, моя аудитория — предприниматели без большого опыта в маркетинге.

[Задача] Напиши образовательную статью о контент-маркетинге для начинающих.

[Формат] Структура:
- Вводный параграф с хуком
- Что такое контент-маркетинг (простыми словами)
- 5 типов контента с примерами
- Пошаговый план запуска
- FAQ (3-5 вопросов)
- Заключение с CTA

[Ограничения]
- Длина: 1200-1500 слов
- Тон: дружелюбный, но экспертный
- Избегай сложных терминов
- Используй реальные примеры

[Пример] Вот стиль, который мне нравится: [ссылка на статью]
```
